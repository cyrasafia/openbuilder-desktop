# 主界面布局设计

对应 spec-v0.1。布局框架的最终依据，后续交互设计不得与本文冲突；修订需更新本文。

## 1. 总体结构

```
┌────────────────────────────────────────────────────────────────┐
│ 标题栏（拖拽区 + 窗口控制，按系统装饰器策略）                        │
├──────────┬─────────────────────────────────────┬───────────────┤
│ 左栏      │ 工作区 (Workspace)                   │ 右栏           │
│ 项目+会话  │  ┌─ Tab 栏（会话 Tab ｜ 文件 Tab）──┐ │ 文件树          │
│          │  │                                  │ │               │
│ ▼ 项目    │  │  会话: 聊天视图 / 文件: 纯文本视图  │ │ ▸ src/         │
│   proj-a │  │                                  │ │ ▸ docs/        │
│   proj-b │  │                                  │ │   README.md    │
│ ──────   │  │                                  │ │   main.ts      │
│ 会话列表  │  │                                  │ │               │
│  (当前项目)│  └──────────────────────────────────┘ │               │
│          │  ┌─ 输入区（会话 Tab 激活时）─────────┐ │               │
│          │  │ [输入框………………] [发送]            │ │               │
│          │  └──────────────────────────────────┘ │               │
├──────────┴─────────────────────────────────────┴───────────────┤
│ 状态栏：连接状态 ● streaming / degraded / offline ｜ 对账中 ｜ 版本  │
└────────────────────────────────────────────────────────────────┘
```

- 三栏：**左 = 项目列表（+当前项目会话列表）**，**中 = 工作区**，**右 = 文件树**
- 设置弹窗（连接配置等）不占布局，模态呈现

## 2. 尺寸与约束

| 栏 | 初始宽 | 最小宽 | 最大宽 | 可折叠 | 说明 |
|---|---|---|---|---|---|
| 左栏 | 260px | 200px | 360px | ✓ | 折叠后仅留项目图标条（48px） |
| 工作区 | 自适应（flex） | **800px** | — | ✗ | 硬约束，任何窗口尺寸下不小于 800 |
| 右栏 | 300px | 240px | 480px | ✓ | 折叠后隐藏，工具栏按钮唤回 |

- 用 `react-resizable-panels` 实现：工作区 `minSize` 按 800px 换算为百分比并随窗口宽度动态约束；侧栏折叠 = panel `collapsed` 状态
- 窗口 `minWidth = 800 + 200 + 240 - 折叠余量 ≈ 1000px`，`minHeight = 600px`；实际取 1024×640 起步
- 工作区 800px 不可满足时（窗口被用户缩到极小）：优先自动折叠右栏 → 左栏，仍不足则允许出现横向滚动而非压缩工作区
- 布局状态（各栏宽度/折叠态/窗口尺寸）持久化（localStorage），重启还原

## 3. 左栏：项目 + 会话

两个纵向区块（与 v0.1 spec 一致，会话列表挂在左栏而非工作区侧边）：

- **项目区**（上）：项目列表（`GET /project`），当前项目高亮；点击切换项目（触发会话列表与右栏文件树的重新对账）。列表项：目录名 + 最近活跃时间
- **会话区**（下，占剩余高度）：当前项目的会话列表，按最近活跃排序；默认隐藏已归档（`time.archived` 过滤），区底提供"已归档"折叠入口（展开可查看/恢复）
- 会话项操作：点击切换（工作区加载对应 Tab）、右键/悬停菜单：重命名、归档/取消归档、删除
- 底部动作：`+ 新建会话`
- 无项目/未连接时：此栏显示引导态（去设置配置服务器）

## 4. 中栏：工作区（≥800px）

Tab 容器，两类 Tab 混排：

- **会话 Tab**：内含聊天视图（消息流 + 底部输入区）。多个会话 = 多个 Tab；Tab 标题 = 会话标题（无标题时取首条消息摘要），流式进行中显示动态指示
- **文件 Tab**：文件树点击文件 → 工作区新开（或复用同文件）纯文本 Tab；标题 = 文件名，dirty 态不存在（v0.1 只读）
- Tab 规则：可关闭（会话 Tab 关闭仅移出工作区，不删会话）；会话 Tab 靠左簇、文件 Tab 靠右簇；切换用 Ctrl+PgUp/PgDn（快捷键体系 v0.2 再统一）
- 输入区仅在会话 Tab 存在；多行输入、Ctrl+Enter 发送（Enter 换行，先按此约定，v0.2 可配置）
- 空态（无任何 Tab）：新建会话引导 + 最近会话快捷列表

## 5. 右栏：文件树

- 数据：`GET /file?path=…` 懒加载逐层展开；展开态按项目记忆
- 交互：点击文件 → 工作区开文件 Tab；目录单击展开/折叠；单一激活项目 = 树根
- 排序：目录优先、字母序；隐藏 dotfiles（默认开，可切）
- v0.1 不做：拖放、搜索、右键操作（新建/重命名/删除）、文件监听刷新（切回 Tab 时重拉）
- 顶部：路径面包屑（截断中间段）

## 6. 状态栏（三栏下方，全宽）

- 左：连接状态点 + 文案（`streaming` / `degraded（重连中）` / `offline` / `对账中`），点击弹出服务器信息（URL、版本 `GET /global/health`）
- 右：当前 agent/model（v0.1 只读展示）+ 应用版本
- 对账进行中显式可见（spec §对账策略 5 的可观察性要求）

## 7. 设置弹窗

- 触发：左栏底部齿轮 / 状态栏 / 首次启动无配置时自动
- 内容（v0.1）：连接 profile 列表（新建/编辑/删除/激活）；managed 模式开关（发现本机 opencode → spawn）
- 弹窗期间主界面继续跑事件流；切换激活 profile = 全量重对账（回到 snapshot 态）

## 8. 主题与视觉基线

- 深/浅色跟随系统（GNOME 深色偏好），v0.1 仅原生 CSS 变量两套色板，不引主题系统
- 视觉细节（间距/字体/色值）后续在根目录 `DESIGN.md`（视觉设计文档）细化，本文只锁结构与尺寸约束
