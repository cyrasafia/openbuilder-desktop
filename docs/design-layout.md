# 主界面布局设计

对应 spec-v0.1。布局框架的最终依据，后续交互设计不得与本文冲突；修订需更新本文。

## 1. 总体结构

```
┌────────────────────────────────────────────────────────────────┐
│ 标题栏（Linux 自定义头部：拖拽区 + 窗口控制；其余平台系统装饰）      │
├──────────┬─────────────────────────────────────┬───────────────┤
│ 左栏      │ 工作区 (Workspace)                   │ 右栏           │
│ 项目+会话  │  ┌─ Tab 栏（会话 Tab ｜ 文件 Tab）──┐ │ 文件树          │
│          │  │                                  │ │               │
│ ▼ 项目    │  │  会话: 聊天视图 / 文件: 纯文本视图  │ │ ▸ src/         │
│   proj-a │  │                                  │ │ ▸ docs/        │
│   proj-b │  │                                  │ │   README.md    │
│ ──────   │  │                                  │ │   main.ts      │
│ 会话列表  │  │                                  │ │               │
│  (当前项目)│  └──────────────────────────────────┘ │               │
│          │  ┌─ 输入区（会话 Tab 激活时）─────────┐ │               │
│          │  │ [输入框………………] [发送]            │ │               │
│          │  └──────────────────────────────────┘ │               │
├──────────┴─────────────────────────────────────┴───────────────┤
│ 状态栏：连接状态 ● streaming / degraded / offline ｜ 对账中 ｜ 版本  │
└────────────────────────────────────────────────────────────────┘
```

- 三栏：**左 = 项目列表（+当前项目会话列表）**，**中 = 工作区**，**右 = 文件树**
- 设置弹窗（连接配置等）不占布局，模态呈现
- **标题栏（2026-08-24 增补）**：Linux 用自定义头部——main 侧 `frame: false`（GNOME/Wayland 下 CSD 本就由应用自绘），renderer 侧 `title-bar.tsx`：整体为拖拽区（`-webkit-app-region: drag`，双击最大化/还原用 Electron 原生行为，不另挂 dblclick），右侧**最小化/最大化还原/关闭**三按钮（IPC `win:*`，关闭按钮 hover 用 error/on-error token）；高度 36px（`--titlebar-h`），配色全走主题 token，跟随 `data-theme` 深/浅切换；按 `desktop.platform === "linux"` 门控渲染，macOS/Windows 及纯浏览器 shim 沿用系统装饰/不渲染

## 2. 尺寸与约束

| 栏 | 初始宽 | 最小宽 | 最大宽 | 可折叠 | 说明 |
|---|---|---|---|---|---|
| 左栏 | 260px | 200px | 360px | ✓ | 折叠后仅留项目图标条（48px） |
| 工作区 | 自适应（flex） | 无（0） | — | ✗ | ~~800px 硬约束~~（已取消，2026-08-23）：窗口可任意缩窄 |
| 右栏 | 300px | 240px | 480px | ✓ | 折叠后隐藏，工具栏按钮唤回 |

- 消息区/输入区**动态宽度 [600, 800]px（不含 padding）**、相对工作区居中；工作区更宽时两侧留白，窗口较窄时收到 600（阅读行宽约束，与 Tab 类型无关，仅 chat 视图；2026-08-23 修订，原固定 600px）。消息列表滚动但**不显示滚动条**
- ~~`react-resizable-panels`~~（v0.1 未用组件库，CSS grid + 变量实现；拖拽调宽留 v0.2）
- 窗口 `minWidth = 680px`（600px 消息区 + 余量），`minHeight = 480px`
- 布局状态（各栏宽度/折叠态/窗口尺寸）持久化（localStorage），重启还原（v0.2）

## 3. 左栏：项目 → 工作区（两级树）

左栏为两级树，**仅项目与工作区**（会话列表已移至中栏，2026-08-23 修订；2026-08-23 二次修订：中栏默认视图由会话列表改为新 Tab 引导页，归档会话恢复经引导页，见 §4）；工作区从属项目、**全部展开展示**（每个打开项目都列出其 worktree）。

- **项目行**（一级）：**仅显示"打开"状态的项目**；**点击项目本身 = 选择该项目的当前作用域**——高亮当前选中行；行：目录名 + 最近活跃时间；当前项目行内可关闭项目
- **会话状态指示器**（项目行 + 工作区行右侧，2026-08-23 增补；2026-08-24 修订：运行点动效改为光晕呼吸）：展示该行作用域（项目行 = 主工作区，工作区行 = 该 worktree）未归档、非 subagent 会话的状态，与中栏会话列表同源（`sessionsInDirectory`，busy 判定同 `busySessions`）；≤4 个逐会话状态点（**运行中 = 双层圆点光晕呼吸**：稳定中心点 + 外圈 scale 0.75→1.15 / opacity 0.2→0.55、1200ms easeInOut 往复，同移动端效果，参考 openbuilder `design-agent-status-indicator.md` §动效设计；`prefers-reduced-motion` 时静态双层；灰点 = 空闲，最近活跃靠左；Tab 栏 chat Tab 前的运行点同款），>4 个收起为数字（任一流式时数字前保留一个运行点）；指示器靠右浮层，**默认覆盖行内操作按钮**（关闭项目/新建工作区/删除工作区），**hover 至行时隐藏指示器、显示操作按钮**；非订阅目录（非当前 worktree）的行以最近快照为准。状态栏 SSE 连接点（`.status-dot.running`）不参与呼吸，保持静态实心
- **工作区行**（二级，跟随项目展示）：每个打开项目下平铺其 worktree 列表（数据源 `Project.sandboxes`）；**"主工作区"即项目行本身**（不单列）；worktree 行：图标（16px 线性，lucide `folder-git-2`）+ 名称 + 分支，行整体相对项目名缩进 16px 以区分层级；点击切换作用域——**先切换后加载**（2026-08-24 增补：点击后左栏高亮/中栏标题/右栏文件树即时跟手，会话快照与作用域 Tab 恢复后台加载后补齐，见 [design-tab-memory.md](./design-tab-memory.md) §6/§16）；跨项目点工作区行 = 开项目并直达该工作区（单次切换）；仅当前项目的 worktree 提供 **创建**（`POST /experimental/worktree`，名称可空=随机 slug；**创建成功后默认切换到新 worktree**，2026-08-23 增补）/ **删除**（`DELETE /experimental/worktree`，二次确认；删除当前 worktree 后自动切回主工作区）
- **项目状态模型**：打开 ∪ 关闭 = 项目全集（`GET /project`）。**打开/关闭是纯客户端状态**，本地持久化（按 profile 维度），server 无此概念：
  - **打开**：左栏展示 + **实时更新**——事件流（会话增删改、消息、状态）应用于该项目，排序/活跃时间随之刷新
  - **关闭**：不展示 + **不更新**——其事件一律忽略（非仅 UI 隐藏），本地不维护其状态；重新打开时走 REST 快照（项目会话列表全量重拉）恢复
  - 事件分发即以打开集合为闸门：`session.*`/`message.*` 事件按 projectID 过滤，未命中打开集合直接丢弃（对账逻辑见 spec）
  - 打开：从"打开项目"选择器（列全集减已打开）中选取；v0.1 打开动作即设为当前项目
  - 关闭：左栏移除；其会话/文件树状态随之卸载，该项目 chat Tab 关闭（不归档）；若是当前项目则切到最近活跃的打开项目（无则空态）；server 侧数据不动
  - 首次连接：默认打开"当前项目"（`GET /project/current`）+ 最近活跃的 1 个
- 无项目/未连接时：此栏显示引导态（去设置配置服务器）

## 4. 中栏：工作区

多类型 Tab 容器，扩展型设计：Tab 类型注册制，每类 Tab 声明 `kind`、图标、标题解析、内容组件与生命周期（挂载/卸载/激活）。v0.1 落地前两类，其余类型在架构文档"未来扩展"中已预研：

| Tab 类型 | 内容 | 版本 |
|---|---|---|
| `chat` 会话 Tab | 聊天视图（消息流 + 底部输入区）；标题 = 会话标题（无标题时取首条消息摘要），流式进行中显示动态指示 | v0.1 || `file` 文件 Tab | 文件树点击文件 → 新开（或复用同文件）纯文本视图；标题 = 文件名；无 dirty 态（只读） | v0.1 |
| `diff` | 会话内变更 diff（@pierre/diffs，会话事件触发） | v0.2（M2） |
| `terminal` | xterm.js + pty 会话（server pty API） | v0.2（M2） |
| `browser` | WebContentsView 内嵌浏览器 tab | v0.3+ |
| `editor` | CodeMirror 6 编辑器 | v0.3+ |

- Tab 规则：可关闭；同 kind 内按打开顺序，不同 kind 混排（注册制下统一顺序 + kind 图标区分）；切换用 Ctrl+PgUp/PgDn（快捷键体系 v0.2 再统一）
- Tab 标识稳定：chat = sessionID、file/diff = 文件路径、terminal = ptyID、browser = URL；重复打开同标识复用已开 Tab 并激活
- **chat Tab 与 session 生命周期绑定（对称语义）**：
  - 新建 chat Tab = 新建 session（`POST /session`），Tab 即 session 的工作区化身
  - **关闭 chat Tab = 归档 session**（`PATCH time.archived`）——Tab 关闭不提供"仅关闭不归档"的路径，交互语义唯一
  - **打开 chat Tab = 取消归档**（`PATCH time.archived=0`）——含从会话列表/归档区点击打开（2026-08-23 修订，原"可选取消归档"）
  - 流式进行中关闭 Tab：先 abort（`POST /session/{id}/abort`）再归档，需二次确认
- 生命周期约束：关闭 Tab 即卸载其订阅/状态；非 chat Tab 重开无状态恢复成本，chat Tab 重开走 REST 消息快照 + 增量
- **Tab 跨项目混排（2026-08-23 修订，原"切项目 = Tab 全关 + 归档"）**：
  - **切换项目/工作区不关闭、不归档任何 Tab**——已有 chat Tab 保留（后台作用域的事件仍正常累积）
  - **Tab 条按作用域过滤显示**：只显示当前作用域的 chat Tab（directory 匹配）+ 全部 file Tab；其他项目的 Tab 隐藏（不关闭），切回时恢复显示——Tab 全集跨项目保留，呈现作用域隔离
  - 打开/切换项目（含工作区）时按 **worktree 级 Tab 记忆**恢复（2026-08-24 修订，原"自动打开最近活跃前 8"）：首次打开的作用域全量开未归档会话（created 升序），有记忆的作用域按记忆恢复 Tab 与顺序；关闭项目清除该项目记忆；作用域无 Tab 则显示会话列表视图。详见 [design-tab-memory.md](./design-tab-memory.md)
  - 关闭 Tab 后的激活回退：只在当前作用域可见 Tab 内选择（不会激活到隐藏 Tab）
  - **关闭项目**：仅关闭该项目所属的 chat Tab（不归档），其余 Tab 不动
  - file Tab 不受作用域切换影响
- 输入区仅在会话 Tab 存在；多行输入、**Enter 发送**（Ctrl/Shift/Alt/Meta+Enter 换行；2026-08-23 修订，原约定 Ctrl+Enter 发送）
- 默认视图（无激活 Tab）＝ **新 Tab 引导页**（2026-08-23 修订，原"作用域会话列表"）：
  - 居中大输入框：输入消息发送即 **新建会话 + 发送首条消息**——首条消息发送成功才开 Tab 并激活（引导页退出）；失败保留草稿、重试复用同一会话（不产生空 Tab），错误经状态栏可见；Enter 语义与聊天输入区一致（裸 Enter 发送、修饰键+Enter 换行、IME 组合中不触发）
  - 输入框下方 **已归档会话列表**（当前作用域，按最近活跃排序）：点击 = 取消归档并开 Tab（与"打开 Tab = 取消归档"对称语义一致）
  - 终端/网页 Tab 入口以禁用态预留（`terminal` v0.2、`browser` v0.3+）
  - 触发时机：新建项目/工作区后（作用域无 Tab）、Tab 栏 **"+"**（2026-08-23 修订，原直接新建会话）、作用域无任何 Tab
  - 已知取舍：会话"重命名/删除"UI 暂无入口（随 v0.2 chat 视图头部补齐）；未归档会话仅经作用域切换的自动开 Tab（上限 8）可达，超出部分暂无列表入口

## 5. 右栏：文件树

- project-scoped：树根 = 当前项目；切换项目时整树重置重拉（与工作区联动，见 §4）
- 数据：`GET /file?path=…` 懒加载逐层展开；展开态按项目记忆
- 交互：点击文件 → 工作区开文件 Tab；目录单击展开/折叠
- 排序：目录优先、字母序；隐藏 dotfiles（默认开，可切）
- v0.1 不做：拖放、搜索、右键操作（新建/重命名/删除）、文件监听刷新（切回 Tab 时重拉）
- 顶部：路径面包屑（截断中间段）

## 6. 状态栏（三栏下方，全宽）

- 左：连接状态点 + 文案（`streaming` / `degraded（重连中）` / `offline` / `对账中`），点击弹出服务器信息（URL、版本 `GET /global/health`）
- 右：当前 agent/model（v0.1 只读展示）+ 应用版本
- 对账进行中显式可见（spec §对账策略 5 的可观察性要求）

## 7. 设置弹窗

- 触发：左栏底部齿轮 / 状态栏 / 首次启动无配置时自动
- 内容（v0.1）：连接 profile 列表（新建/编辑/删除/激活）；managed 模式开关（发现本机 opencode → spawn）
- 弹窗期间主界面继续跑事件流；切换激活 profile = 全量重对账（回到 snapshot 态）
