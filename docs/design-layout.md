# 主界面布局设计

对应 spec-v0.1。布局框架的最终依据，后续交互设计不得与本文冲突；修订需更新本文。

## 1. 总体结构

```
┌────────────────────────────────────────────────────────────────┐
│ 标题栏（Linux 自定义头部：拖拽区 + 窗口控制；其余平台系统装饰）      │
├──────────┬─────────────────────────────────────┬───────────────┤
│ 左栏      │ 工作区 (Workspace)                   │ 右栏           │
│ 项目+会话  │  ┌─ Tab 栏（会话 Tab ｜ 文件 Tab）──┐ │ 文件树          │
│          │  │                                  │ │               │
│ ▼ 项目    │  │  会话: 聊天视图 / 文件: 纯文本视图  │ │ ▸ src/         │
│   proj-a │  │                                  │ │ ▸ docs/        │
│   proj-b │  │                                  │ │   README.md    │
│ ──────   │  │                                  │ │   main.ts      │
│ 会话列表  │  │                                  │ │               │
│  (当前项目)│  └──────────────────────────────────┘ │               │
│          │  ┌─ 输入区（会话 Tab 激活时）─────────┐ │               │
│          │  │ [输入框………………] [发送]            │ │               │
│          │  └──────────────────────────────────┘ │               │
│ ● 实时 ⚙ │                                      │               │
└──────────┴─────────────────────────────────────┴───────────────┘
```

- 三栏：**左 = 项目列表（+当前项目会话列表）**，**中 = 工作区**，**右 = 文件树**
- 设置弹窗（连接配置等）不占布局，模态呈现
- **标题栏（2026-08-24 增补）**：Linux 用自定义头部——main 侧 `frame: false`（GNOME/Wayland 下 CSD 本就由应用自绘），renderer 侧 `title-bar.tsx`：整体为拖拽区（`-webkit-app-region: drag`，双击最大化/还原用 Electron 原生行为，不另挂 dblclick），右侧**最小化/最大化还原/关闭**三按钮（IPC `win:*`，关闭按钮 hover 用 error/on-error token）；高度 36px（`--titlebar-h`），配色全走主题 token，跟随 `data-theme` 深/浅切换；按 `desktop.platform === "linux"` 门控渲染，macOS/Windows 及纯浏览器 shim 沿用系统装饰/不渲染

| 左栏 | 260px | 200px | 360px | ✓ | 折叠后仅留项目图标条（48px） |
| 工作区 | 自适应（flex） | 无（0） | — | ✗ | ~~800px 硬约束~~（已取消，2026-08-23）：窗口可任意缩窄 |

- 布局状态（各栏宽度/折叠态/窗口尺寸）持久化（localStorage），重启还原（v0.2）

## 3. 左栏：项目 → 工作区（两级树）

左栏为两级树，**仅项目与工作区**（会话列表已移至中栏，2026-08-23 修订；2026-08-23 二次修订：中栏默认视图由会话列表改为新 Tab 引导页，归档会话恢复经引导页，见 §4）；工作区从属项目、**全部展开展示**（每个打开项目都列出其 worktree）。

- **项目行**（一级，2026-08-24 修订：加强样式与 worktree 行区分）：**仅显示"打开"状态的项目**；**点击项目本身 = 选择该项目的当前作用域**——高亮当前选中行；行 = 头像 + 两行文本：头像 26px 圆角（server `icon.override` > `icon.url` 图片（data:/https:，加载失败回退）> 项目名首字母；色 = `icon.color` 命名色 > 名称哈希，与 openbuilder `ProjectAvatar` 跨端同色；色框/淡染底仅字母瓷片有，自定义图片态裸图——2026-08-24，同移动端 foregroundDecoration 仅无图应用）+ 名称（600）+ 路径（`ui-xs` `outline`，行内截断、title 全量），自适应行高与单行 26px 的 worktree 行形成层级对比；"打开项目"选择器行同款；当前项目行内可关闭项目；2026-08-25 修订：hover 行内操作按钮改为**全行显示**——关闭（×）对任意已打开项目/global 目录可用（`closeEntry` 按 key 工作、纯客户端状态无副作用），新建工作区（+）对任意普通项目可用（`createWorkspace(projectId)` 在该非当前项目下创建 worktree 但不切当前作用域，新 worktree 随 SSE 事件到达、切过去即见）；2026-08-24 修订：行三态改纯背景色（未选中透明 / hover `surfaceContainerHigh` / 选中 `surfaceContainerHighest` 叠 4% `onSurface` 微加深），弃用左侧 2px `primary` 竖线——中性底不与行内四色指示器争色，深/浅主题均适用；文件树与"打开项目"选择器行共享 `.tree-row` 一并生效，规格见 DESIGN.md
- **global 项目按 directory 拆分**（2026-08-24 增补）：server 把所有非 git 目录的会话归入 `id==="global"` 的项目（worktree 为 `/`），其会话散布在任意目录（家目录、/tmp、文档目录……），单一"global"行无法表达作用域。左栏将 global 拆为**每个会话目录一行**，行语义与视觉均与普通项目行一致（顶级、点击切作用域、头像 + 名称/路径两行、可独立打开/关闭、无子行——global 非 git 无 worktree、无新建工作区入口）：
  - 行数据源 = 会话快照按 `Session.directory` 聚合（发现查询 `GET /session?scope=project&directory=/` 一次取全量，连接时与选择器打开时刷新——未打开 entry 的目录事件被事件闸门丢弃，新目录只能靠快照发现）；显示名 = 目录末段，根目录 `/` 显示 "global"（同 openbuilder `projectDisplayOf`）；头像无 icon 走名称哈希色
  - 打开/关闭按目录独立持久化（entry 键 `global\0<directory>`，普通项目 = project.id）；关闭 = 卸载该目录会话/状态/Tab/记忆，其余 global 目录不受影响；作用域切换先切换后加载（同 openProject）
  - 排序 = 目录内会话最大 `updated` 降序；已打开但会话全部归档的目录保留行（updated=0 兜底，否则行消失无法导航）
  - 已知局限：目录活跃度随归档下沉（未做 openbuilder 式单调活动表）；显示名可能同名（title 提示全路径区分）
- **会话状态指示器**（项目行 + 工作区行右侧，2026-08-23 增补；2026-08-24 修订：运行点动效改为光晕呼吸）：展示该行作用域（项目行 = 主工作区/global 目录行 = 该目录，工作区行 = 该 worktree）未归档、非 subagent 会话的状态，与中栏会话列表同源（`sessionsInDirectory`，busy 判定同 `busySessions`）；≤4 个逐会话状态点（**琥珀静态点 = 待输入（授权/问题，2026-08-24 增，优先级最高，waiting > running > idle，见 design-pending-cards.md）**；**运行中 = 双层圆点光晕呼吸**：稳定中心点 + 外圈 scale 0.75→1.15 / opacity 0.2→0.55、1200ms easeInOut 往复，同移动端效果，参考 openbuilder `design-agent-status-indicator.md` §动效设计；`prefers-reduced-motion` 时静态双层；灰点 = 空闲，最近活跃靠左；Tab 栏 chat Tab 前的状态点同款（waiting 琥珀/运行光晕）），>4 个收起为按状态聚合的数字 chip（待输入数 = 琥珀字 + 琥珀淡染底、运行数 = 绿字 + 运行色淡染底、空闲数 = 灰 chip，各自为 0 时省略；2026-08-24 修订，替代旧"总数 + 前置状态点"方案）；指示器靠右浮层，**默认覆盖行内操作按钮**（关闭项目/新建工作区/删除工作区），**hover 至行时隐藏指示器、显示操作按钮**；未拉快照目录的行以最近快照为准（单全局流下无订阅概念）。左栏底部连接状态点（`.status-dot.running`）不参与呼吸，保持静态实心；指示点统一 12px 盒，实心点经 ::after 居中入盒：waiting 琥珀 / idle 灰统一 8px（与全应用通用实心点同径；2026-08-25 修订，原 idle 7px 为任意值，与 waiting 8px、running 中心 6px 形成 8/7/6 三档尺寸不一；idle 弱化仅靠 0.55 透明度承载），running 中心点 6px 属光晕呼吸规格（参数对齐移动端）不在统一之列，最右点中心线稳定在右缘 12px；worktree 删除钮为 lucide `trash-2` 16px、项目行新建工作区钮为 `folder-plus` 16px；行内最右操作钮（worktree 删除 / 项目关闭 / 单项目时的新建工作区）图标中心均对齐该中心线（2026-08-24）
- **工作区行**（二级，跟随项目展示）：每个打开项目下平铺其 worktree 列表（数据源 `Project.sandboxes`，global 项目无）；**"主工作区"即项目行本身**（不单列；global 根目录 `/` 行同理）；worktree 行：图标（16px 线性，lucide `folder-git-2`）+ 名称 + 分支，名称文本与项目名文本左对齐（2026-08-24 修订，行 padding-left 16；原"行整体相对项目名缩进 16px"弃用）；点击切换作用域——**先切换后加载**（2026-08-24 增补：点击后左栏高亮/中栏标题/右栏文件树即时跟手，会话快照与作用域 Tab 恢复后台加载后补齐，见 [design-tab-memory.md](./design-tab-memory.md) §6/§16）；跨项目点工作区行 = 开项目并直达该工作区（单次切换）；**创建**（`POST /experimental/worktree`，名称可空=随机 slug；当前项目创建成功后默认切换到新 worktree，2026-08-23 增补）/ **删除**（`DELETE /experimental/worktree`，二次确认；删除当前 worktree 后自动切回主工作区）；2026-08-25 修订：创建/删除按钮 hover **全行显示**，非当前项目的 worktree 亦可删除（`removeWorkspace(directory, projectId)` 清理该项目的会话/Tab/记忆/状态，但不扰动当前作用域——文件树/作用域 Tab 恢复仅对当前项目生效）
- **项目状态模型**：打开 ∪ 关闭 = 项目全集（`GET /project`）∪ global 会话目录（发现快照）。**打开/关闭是纯客户端状态**，本地持久化（按 profile 维度），server 无此概念：
  - **打开**：左栏展示 + **实时更新**——事件流（会话增删改、消息、状态）应用于该项目，排序/活跃时间随之刷新
  - **关闭**：不展示 + **不更新**——其事件一律忽略（非仅 UI 隐藏），本地不维护其状态；重新打开时走 REST 快照（项目会话列表全量重拉）恢复
  - 事件分发即以打开集合为闸门：`session.*`/`message.*` 事件按 directory 放行（单全局流收全量，打开集合外的目录直接丢弃，见 [design-sse-global-event.md](design-sse-global-event.md) §4.2）
  - 打开：从"打开项目"选择器（列全集减已打开：普通项目 + global 目录，按最近活跃排序）中选取；v0.1 打开动作即设为当前项目/作用域
  - 关闭：左栏移除；其会话/文件树状态随之卸载，该项目（global = 该目录）chat Tab 关闭（不归档）；若是当前作用域则切到最近活跃的打开项目/global 目录（无则空态）；server 侧数据不动
  - 首次连接：默认打开"当前项目"（`GET /project/current`；若为 global 则落到最近活跃 global 目录）+ 最近活跃的 1 个普通项目
- 无项目/未连接时：此栏主体显示引导态（去设置配置服务器）；底部服务器状态行仍在（见 §6）

## 4. 中栏：工作区

多类型 Tab 容器，扩展型设计：Tab 类型注册制，每类 Tab 声明 `kind`、图标、标题解析、内容组件与生命周期（挂载/卸载/激活）。v0.1 落地前两类，其余类型在架构文档"未来扩展"中已预研：

| Tab 类型 | 内容 | 版本 |
|---|---|---|
| `chat` 会话 Tab | 聊天视图（消息流 + 底部输入区）；标题 = 会话标题（无标题时取首条消息摘要），流式进行中显示动态指示 | v0.1 || `file` 文件 Tab | 文件树点击文件 → 新开（或复用同文件）纯文本视图；标题 = 文件名；无 dirty 态（只读） | v0.1 |
| `diff` | 作用域改动详情（上一轮/未提交/分支三来源，单 Tab + 页内 segment 切换），见 [design-diff-view.md](./design-diff-view.md) | v0.2（已落地） |
| `terminal` | xterm.js + pty 会话（server pty API） | v0.2（M2） |
| `browser` | WebContentsView 内嵌浏览器 tab | v0.3+ |
| `editor` | CodeMirror 6 编辑器 | v0.3+ |

- Tab 规则：可关闭；同 kind 内按打开顺序，不同 kind 混排（注册制下统一顺序 + kind 图标区分）；切换用 Ctrl+PgUp/PgDn（快捷键体系 v0.2 再统一）
- Tab 标识稳定：chat = sessionID、file = 文件路径、diff = 作用域目录、terminal = ptyID、browser = URL；重复打开同标识复用已开 Tab 并激活
- **chat Tab 与 session 生命周期绑定（对称语义）**：
  - 新建 chat Tab = 新建 session（`POST /session`），Tab 即 session 的工作区化身
  - **关闭 chat Tab = 归档 session**（`PATCH time.archived`）——Tab 关闭不提供"仅关闭不归档"的路径，交互语义唯一
  - **打开 chat Tab = 取消归档**（`PATCH time.archived=0`）——含从会话列表/归档区点击打开（2026-08-23 修订，原"可选取消归档"）
  - 流式进行中关闭 Tab：先 abort（`POST /session/{id}/abort`）再归档，需二次确认
- 生命周期约束：关闭 Tab 即卸载其订阅/状态；非 chat Tab 重开无状态恢复成本，chat Tab 重开走 REST 消息快照 + 增量
- **Tab 跨项目混排（2026-08-23 修订，原"切项目 = Tab 全关 + 归档"）**：
  - **切换项目/工作区不关闭、不归档任何 Tab**——已有 chat Tab 保留（后台作用域的事件仍正常累积）
  - **Tab 条按作用域过滤显示**：只显示当前作用域的 Tab——全 kind 按 `directory` 匹配（chat = 会话目录、diff = 作用域目录、file = 打开时作用域目录；2026-08-25 修订，原"全部 file Tab"全局显示，见 design-tab-memory §18）；其他作用域的 Tab 隐藏（不关闭），切回时恢复显示——Tab 全集跨项目保留，呈现作用域隔离
  - 打开/切换项目（含工作区）时按 **worktree 级 Tab 记忆**恢复（2026-08-24 修订，原"自动打开最近活跃前 8"）：首次打开的作用域全量开未归档会话（created 升序），有记忆的作用域按记忆恢复 Tab 与顺序，并补开记忆外可见会话（他端新建等，2026-08-24 增补见 [design-tab-memory.md](./design-tab-memory.md) §17）；关闭项目清除该项目记忆；作用域无 Tab 则显示会话列表视图。详见 [design-tab-memory.md](./design-tab-memory.md)
  - 关闭 Tab 后的激活回退：只在当前作用域可见 Tab 内选择（不会激活到隐藏 Tab）
  - **关闭项目**：关闭该项目所属的 chat Tab（不归档）及目录归属的 file/diff Tab（2026-08-25 修订，原仅 chat；file/diff 作用域化后不随项目关闭即成永久不可见孤儿）
  - ~~file Tab 不受作用域切换影响~~（2026-08-25 修订：file Tab 作用域化，随作用域切换隐藏/恢复、激活随之清算，见 [design-tab-memory.md](./design-tab-memory.md) §18）
- 输入区仅在会话 Tab 存在；多行输入、**Enter 发送**（Ctrl/Shift/Alt/Meta+Enter 换行；2026-08-23 修订，原约定 Ctrl+Enter 发送）
- **待处理卡片区**（消息流与输入区之间，2026-08-24 增）：agent 请求人工介入（授权/问题）时显示应答卡片，一次一张（授权优先）、队列计数；宽度对齐消息区 [600, 800]px；设计细节见 [design-pending-cards.md](design-pending-cards.md)。Tab 状态点增加 waiting 态（琥珀，优先于运行光晕点）
- 默认视图（无激活 Tab）＝ **新 Tab 引导页**（2026-08-23 修订，原"作用域会话列表"）：
  - 居中大输入框：输入消息发送即 **新建会话 + 发送首条消息**——首条消息发送成功才开 Tab 并激活（引导页退出）；失败保留草稿、重试复用同一会话（不产生空 Tab），错误经左栏状态行可见；Enter 语义与聊天输入区一致（裸 Enter 发送、修饰键+Enter 换行、IME 组合中不触发）
  - 输入框下方 **已归档会话列表**（当前作用域，按最近活跃排序）：点击 = 取消归档并开 Tab（与"打开 Tab = 取消归档"对称语义一致）
  - **Tab 入口行**（2026-08-25 增补）：单个「改动」入口（开作用域唯一 diff Tab，三种改动来源在页内 segment 切换，见 [design-diff-view.md](./design-diff-view.md)）；终端/网页 Tab 入口以禁用态预留（`terminal` v0.2、`browser` v0.3+），三者同行平级
  - 触发时机：新建项目/工作区后（作用域无 Tab）、Tab 栏 **"+"**（2026-08-23 修订，原直接新建会话）、作用域无任何 Tab
  - 已知取舍：会话"重命名/删除"UI 暂无入口（随 v0.2 chat 视图头部补齐）；未归档会话仅经作用域切换的自动开 Tab（上限 8）可达，超出部分暂无列表入口

## 5. 右栏：文件树

- project-scoped：树根 = 当前项目；切换项目时整树重置重拉（与工作区联动，见 §4）
- 数据：`GET /file?path=…` 懒加载逐层展开；展开态按项目记忆
- 交互：点击文件 → 工作区开文件 Tab；目录单击展开/折叠
