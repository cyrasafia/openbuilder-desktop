聚合状态 chip 重设计 · 反色填充 + SVG 圆点（2026-10-11，待目检）

结构：chip = 状态圆点（12px 盒，与 ≤4 逐点态同几何同动效）+ 中性数字； 状态色只落在圆点上，数字/容器全状态一套中性样式（原四变体族已删）。
容器（颜色已定案）：无描边，反色填充——胶囊 = 行态对侧色：未选中行填「选中灰」、选中行填「行底色」。 边界对比恒等于选中信号步幅（深 1.56:1 / 浅 1.26:1，两行态对称）。
圆点改 inline SVG：Chromium 在分数 DPR 下把 6px border-radius 圆点按位置相位 光栅化成扁/竖椭圆（DevTools 量仍是 6×6——你看到的「胶囊形」即此）；SVG 路径光栅化相位不敏感 （16 相位 × DPR 1.25/1.1 实测全部同几何），光晕/弱化/呼吸同规格保留；光晕 svg 加 overflow:visible（svg 默认裁剪到视口，呼吸最大 scale 1.15＝12.65px 会切边）。
排序（对齐移动端）：running → error → failed → waiting → unread → idle，为 0 的态省略。 行 hover 时指示器整体隐藏，故只呈现「未选中 / 选中」两种行底。数字 1px 下移光学居中 （分数 DPR 下文字基线量化，残余 ~0.3px 为引擎下限）。
