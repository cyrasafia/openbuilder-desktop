聚合状态 chip 重设计 · 终案目检（2026-10-11 用户定案）

结构：chip = session-* 状态圆点（12px 盒，与 ≤4 逐点态同几何同动效，呼吸免费继承）+ 中性数字； 状态色只落在圆点上，数字/容器全状态一套中性样式（原四变体族删除）。
容器（终案）：surface-container-high 实底 + 1px outline-variant 细描边——实底令内容对比不随行态漂移； 描边承载胶囊边界（深 1.7:1 / 浅 1.4:1，未选中行上可见；纯实底上限仅 ~1.2:1 不足，error 红点 3:1 门限钉死实底档位）。
排序（对齐移动端 2026-10-11 裁定）：running → error → failed → waiting → unread → idle，为 0 的态省略。 行 hover 时指示器整体隐藏，故只呈现「未选中 / 选中」两种行底。
