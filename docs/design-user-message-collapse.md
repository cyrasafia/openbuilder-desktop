# 高用户消息折叠/展开

参考：`../openbuilder/docs/design-user-message-collapse.md`（移动端同名设计，历经四期：判定防振荡、气泡级 clamp 壳、反转列表滚动校正、两态手势统一）。桌面端 DOM + CSS 实现没有反转列表滚动几何与 widget 实例缓存问题，只借鉴其核心判定与交互结论，未重蹈其逐期修补的坑。

## 问题

用户消息可以任意长（粘贴日志、长 prompt）。长用户消息在会话流里占据数屏，把真正要看的 agent 回复推远。需要：高用户消息默认收起，点击展开/收起。

## 决策

### 1. 门槛 = 20 行正文（桌面口径，不同于移动端）

移动端用「屏幕可见区域 40%」；桌面改用**行数口径**——桌面窗口高度可变（缩放/半屏/多显示器），按屏占比门槛会随窗口大小漂移，行数口径稳定且符合「约 20 行正文高度」的直觉。行高取正文 markdown 计算样式（`.markdown-body` 14px × 1.6 = 22.4px/行，缺样式回落同值），门槛 = 20 × 行高。

最小收益 24px（沿用移动端 `_kUserCollapseMinGain`）：自然高度超出门槛不足约一行时不折叠——收起只省一行、却多一次点击，收益太小。

### 2. 双层 DOM 结构性消解判定振荡

移动端的核心坑：折叠态测得的是 clamp 后高度，若与自然高度同 map 存放会振荡（折叠→测矮→判不可折叠→展开→测高→折叠…），靠「自然高/渲染高双 map 分账 + 渲染分支守卫」解决。

桌面端用结构规避：内容层 `.bubble-content` **永不加高度约束**、恒自然高度；裁切只发生在外层 `.bubble`（`max-height` + `overflow: hidden`，border-box 口径，+20px = 气泡上下 padding）。测高永远读内容层 `offsetHeight`——口径与收起态无关，无需分账。

- 首测在 `useLayoutEffect`（首绘前完成，无移动端「先展开后折叠」的一帧闪现）；
- `ResizeObserver` 盯内容层：窗口宽度变化 → 文本重排 → 高度变化 → 重判定（跨门槛双向都走，收窄后不再超门槛的消息自动摘掉折叠壳）。

### 3. 交互：整面点击切换 + 三类豁免

点击气泡任意处切换展开/收起（移动端三期统一后的最终形态）。豁免：

1. **链接**（`closest("a")`）：交给系统浏览器（`target=_blank` → main 进程 openExternal），不触发切换；
2. **按钮**（`closest("button")`）：代码块复制钮等；
3. **气泡内文本选择非空**（`anchorNode` 在内容层内）：划选收尾的 mouseup 会派发 click，此时收起会吞掉用户刚选中的内容上下文。选区限定气泡内——别处（其他消息/文件树）的残留选区不拦截本气泡点击（评审收紧）。

桌面正文是普通 DOM 文本（非移动端 SelectableText），无焦点抢占、无内部手势仲裁——移动端三期的 `ExcludeFocus`/`onTapText` 观察/横滚转发等问题域不存在。

### 4. 视觉

- **收起态**：气泡底部渐变（`transparent → --color-user-bubble`）+ 居中 `ChevronDown`，`pointer-events: none` 纯视觉（点击由气泡整面承担，同移动端「指示纯视觉、壳层管手势」契约）。渐变收在气泡底色上，明暗主题同值（`--color-user-bubble` 两主题相同）。
- **展开态**：正文之下独占一行 `ChevronUp`（16px 高）——不遮挡末行内容（移动端二期「浮标遮正文」问题的桌面版解法：直接不叠加）。
- `title` 提示当前动作（点击展开/点击收起）。

### 5. 不做的事（对齐移动端结论）

- **不折叠 assistant 消息**：agent 回复是对话主体，折叠违背阅读目的；
- **无动画**：瞬时切换，同项目 chip 条件渲染先例（design-chip-style-unify 移动端同款结论「对齐全项目折叠先例，零动画」）；
- **不持久化展开态**：组件内状态，会话内保持；Tab 重挂载（关闭重开/切项目）回到默认收起，可接受；
- **不做流式用户消息折叠**：用户消息落库即定稿（乐观气泡是独立分支，秒级收敛），无边流式边判定的需求。

## 验收（user-bubble.test.tsx，5 例）

| 场景 | 断言 |
|------|------|
| 短消息（100px） | 不挂 `user-collapse`/`collapsed` 类、无提示元素、点击无反应 |
| 高消息（2000px） | 默认收起 + 渐变提示 + title「点击展开」；点击展开（提示换 `ChevronUp`、title「点击收起」）；再点回收起 |
| 点击气泡内链接 | 不触发切换 |
| 文本选择时点击 | 气泡内选区非空 → 不切换；气泡外残留选区 → 不拦截 |
| resize 重判定（RO 桩触发） | 跌出门槛 → 摘掉折叠壳（双向都走）；跨回门槛 → 恢复默认收起 |

全量 277 测试通过；`tsc` 双 tsconfig 零错误。
